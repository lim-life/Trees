## 判据
在 Git Bash / MSYS 环境里写路径、重定向输出时。

## 做法
用 `/dev/null`。Windows 的 `NUL` 在这个环境里会被当成一个普通文件名,
于是你以为丢掉了输出,其实在当前目录建了个名叫 NUL 的文件。

## 不适用
原生 PowerShell / cmd —— 那里 `NUL` 才是对的,`/dev/null` 反而会被当路径。
