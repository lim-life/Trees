# 共享森林框架：证据、分层与先知

> 状态：**已确认的基本框架**。
> 日期：2026-10-22 · 关联：[00-SPEC.md](00-SPEC.md) 规则 7 / 8

---

## 0. 一句话

**知识不能投票；可信度由证据阶梯、独立复现和时间决定。**

---

## 1. 基本立场

### 1.1 知识不能投票

- 多数人的判断依赖当下共识，而新知识按定义就是反共识的
- 投票看的是表达力、人气和阵营，不看正确性
- 因此：不为"先知"设评选委员会；不按票数决定可信度
- 替代方案：证据阶梯（§2）+ 独立复现 + 时间

### 1.2 学习即拥有，血缘归森林

- 知识被调用后落到本地，使用者可以基于它长出**自己的新树**
- 复制品归学习者；派生关系记 `derived_from`
- 同步时只上报哈希与计数，不上报内容（隐私与可追溯同时成立）
- 学走的是内容，留下的是血缘

### 1.3 原件不删，可撤回

- 错误的树不删除，只隔离、降权、发墓碑
- 撤回沿 `bloodline` 传播到所有派生树
- 这是可审计与可修复的共同前提

### 1.4 自己的树权重最高（规则 7）

- 召回排序：自己种的 1.0 > 本机导入的 > 陌生人共享的
- 权重是**信任的先后**，不是"谁更对"；别人的树被验证够多可以反超
- 只影响召回排序与可见度，不改 `watered` / `state` / `last_watered`

### 1.5 树牌先行（规则 8）

- 每棵大树必须有 `plaque`（一句话）+ `labels`（标签）+ 植树人 + 证据
- 列表、索引只显示树牌；正文只在 `trees tree <id>` 时打开
- 树牌是索引，不是抽象；正文里的具体经验原样保留
- 树牌若由 AI 生成，必须标注并允许人改

## 2. 证据阶梯

| 级 | 证据 | 判定方式 | 可信度 |
|---|---|---|---|
| **L0 猜想** | 作者自述，任何人可提 | 人工阅读 | 最低，仅保存 |
| **L1 形式化证明** | Lean / Coq / Isabelle | 机器检查 | 数学、逻辑类最高 |
| **L2 独立复现** | 不同团队、不同环境重复成功 | 验证记录 + 环境指纹 | 高 |
| **L3 同行评审发表** | 期刊 / 会议 + DOI | 学术出版 | 中，**入场券** |
| **L4 长期跨域使用** | N 年、M 个领域持续被用 | 系统统计 | 高 |
| **L5 外部顶级奖项** | 诺奖 / 菲尔兹 / 图灵等 | 外部世界 | 确认信号，不等于全对 |

### 规则

- **L3 ≠ 正确**：发表只代表"值得进入复现队列"
- **L2 / L4 是核心证据**：真实复现和长期使用最难伪造
- **L5 是确认信号**，不能替代独立复现，也不能因为得奖就停止质疑
- 任何一级都可被撤回；撤回沿血缘传播（§5）
- 单一等级不能决定一切；可信度是组合，不是加总

## 3. 结构分层

### 3.1 三种依赖边

```
derived_from        从哪颗学来的
synthesized_from    由哪几颗合成
depends_on          用之前必须先懂哪颗
```

### 3.2 由结构判定层级

| 层级 | 结构特征 | 含义 |
|---|---|---|
| **基石** | 高中心性、**低前置依赖** | 很多树靠它，它不靠别人 |
| **乔木** | 高中心性 + 跨域独立使用 | 被反复验证的成熟树 |
| **苗圃** | 低中心性 + 高新颖性 | 还没验证，可能是未来的基石 |
| **先知** | 长期低使用 + 后期被追溯引用 | 只有时间能认出来 |

中心性用 PageRank / 介数中心性计算；**人不指定层级**。

### 3.3 可信度公式（草案）

```
credibility = 结构中心性^a
            × 独立复现次数^b
            × 环境 / 植树人多样性^c
            × 存续时间^d
            × (1 − 作弊惩罚)
```

- `a,b,c,d` 公开、可调、可审计
- 只用于**召回排序与可见度**，不改变种子状态
- 任一因子为 0 时归零（例如已撤回）

### 3.4 风险

中心性可以被伪造依赖刷高。必须叠加：

- 只认不同植树人的独立复现
- 检测互惠环与团簇（A 浇 B、B 浇 A）
- 单人权重封顶
- 中心性只作为信号之一，不单独决定分层

## 4. 两类先知

### 4.1 可验证型

论文、证明、可复现实验。

- 走证据阶梯快车道：L3 → L2 → L4
- 不需要评选，只需要被复现
- 学术验证是**过滤器**，不是真理机器

### 4.2 猜想型

可能几十年后才被证明的想法。

- 猜想池：陈述、背景、可判定性、已知反例
- 长期保存，保证不丢；**猜想本身不提高可信度**
- 解决（证明 / 反例）后才升级证据等级
- 能形式化的猜想（Lean statement）优先，至少在表述层面可机器判定
- 若几十年后成为基石，再追溯确认

### 4.3 少数派保护

- 共识否定 ≠ 删除；只降权、隔离、留档
- 既然承认"先知是少数"，系统必须能保存今天的异端
- 今天的错误可能是明天的正确；墓碑只在被证伪后立

## 5. 证据失效与撤回

```
DOI 撤稿 / 复现失败 / 环境失效
  → 定位相关种子
  → 沿 bloodline 下溯
  → 所有派生树标记「待复核」
  → 复核通过则恢复，否则降权 / 隔离
```

- 接：Retraction Watch、PubPeer、arXiv 撤稿、期刊更正、依赖工具版本变更
- 撤回不删除内容，只发墓碑；历史记录保留
- 这是"自愈"在证据层面的实现

## 6. 与现有系统的映射

### 6.1 新增字段

**种子 Seed**

```yaml
planter: zzx                    # 植树人
evidence_level: L2              # L0–L5
external_ids: { doi, arxiv, orcid }
retracted: false
conjecture_status: null         # proposed | resolved | refuted
formalization: null             # lean / coq 文件指针
derived_from: []                # 学自哪些种子
```

**大树 Tree**

```yaml
planter: zzx
plaque: 一句话说清这棵树解决什么问题
labels: [工业设计, 硬件, 演示]
```

### 6.2 新增命令（草案）

```
trees evidence <seed> --level L2 --ref <doi>
trees retract <doi>
trees conjecture "<陈述>"
trees resolve <seed> --proof <file>
trees centrality                 # 离线输出结构中心性报表
trees plaque <tree>              # 查看/修改树牌
```

### 6.3 状态机映射

| 现有状态 | 共享森林中的位置 |
|---|---|
| `buried` / `sprouting` | 苗圃层 |
| `growing` | 公共可见 |
| `advanced` | 乔木层 / 成熟 |
| `boxed` | 长期未用，可唤醒 |
| 新增 `retracted` | 墓碑，可信度归零 |

### 6.4 不改的东西

- 浇水驱动状态机
- 合成需人审、原件不删、可回拆
- 项目完成才播种
- 会话树只是原料
- 数据仍是纯 Markdown，可 git 管理
