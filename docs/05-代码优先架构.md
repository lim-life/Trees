# 代码优先：哪些由程序做，哪些才交给 AI

> 2026-10-28 · 关联：[00-SPEC.md](00-SPEC.md) · [04-联邦与防护.md](04-联邦与防护.md)

## 0. 一句话

**AI 只做它不可替代的两件事：理解/抽取文本，给知识打向量分。**
统计、校验、分配、撤回、发布、校验链，全部由代码完成。

## 1. 分工

| 任务 | 执行者 | 现状 |
|---|---|---|
| 从项目材料提取种子 | AI（受限 prompt） | ✅ |
| 向量打分 D1/D2/D4 + D3 先验 | AI（统一 scorer） | ✅ |
| 近重复的语义判定 | AI（只判候选对） | ✅ |
| 黑夜学习（dream） | AI（预算内） | ✅ |
| 事件账本 / 哈希链 | 代码 | ✅ |
| 精确查重 / 归一化 | 代码 | ✅ |
| 召回排序 / 预算裁剪 | 代码 | ✅ |
| 索引 / 树牌 | 代码 | ✅ |
| 选择性发布 / manifest 哈希 | 代码 | ✅ |
| 统计（状态/植树人/事件/调用） | 代码 | ✅ |
| 撤回传播 | 代码 | ⬜ |
| 权重分配 / 结算 | 代码 | ⬜ |
| 守护进程 / 定时任务 | 代码 | ⬜ |
| 依赖图 / 知识包拓扑 | 代码 | ⬜ |
| 真假 / 证据等级 | 独立复现 + 证据 | 不由 AI 定 |
| 高危内容终审 | 规则 + 人审 | 不由 AI 单独定 |

## 2. Scorer 合约

- 独立配置：`forest/config.json` 的 `scorer`，可回退到主模型
- 固定 rubric、严格 JSON、`temperature=0`
- 版本：`trees-scorer/1`；换模型/改标尺必须重打分
- 缓存：`forest/scores.json`，键 = `contentHash + scorerVersion`，同一内容不重复花钱
- 输出：`d1` 抽象度、`d2` 领域、`d3` 先验调用价值、`d4` 风险
- **D3 不进向量距离**，只作为排序先验；之后由事件账本更新
- **不参与**：真假、证据、撤回、审核、发放

## 3. 统计与分配

- `stats.js` 纯函数：种子状态、植树人、事件类型、每颗种子的使用次数
- 全部来自本地文件，不调模型、不花钱、可测试
- 分配原则（下一步实现）：
  - 发放只由**可审计事件**触发
  - D3 由事件更新，不由模型改
  - 公式、系数公开，可回放

## 4. 为什么代码优先

- **可复现**：同一份数据跑出同一结果
- **可测试**：191 项测试兜底，改一处能立刻知道坏没坏
- **成本可控**：模型只花在文本理解上
- **抗注入**：统计/校验不读模型输出当命令
- **可上链**：哈希链和事件天然可锚定
